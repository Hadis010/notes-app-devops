# Module Database

Gestion de la base de données MySQL pour Tiny Notes App.

## Responsabilités

- Provisionnement d'une base MySQL dédiée
- Déploiement en réseau privé
- Restriction des accès aux seules instances applicatives
- Configuration des paramètres de stockage
- Préparation de la stratégie de sauvegarde

## Usage

Ce module est déployé dans les sous-réseaux privés fournis par le module `network`.
